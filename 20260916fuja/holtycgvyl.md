# 【微医讯】海南医院成功开展髂动脉分叉支架系统治疗髂动脉瘤手术

> 更新时间：2026-09-16 (UTC+8)

近日，解放军总医院海南医院血管外科利用全腔内微创介入技术，完成海南省首例**髂动脉分叉支架系统治疗髂动脉瘤手术**，彰显出海南医院血管外科微创治疗的先进水平。

　　患者刘某，48岁，在当地医院体检时发现患有右髂总动脉瘤，累及髂内动脉，瘤体直径已超过3cm，存在破裂风险。由于瘤体位置特殊、治疗难度大，患者辗转长沙及海口各大医院治疗无果后，来到海南医院就诊。此类疾病常规方案是利用直筒覆膜支架进行治疗，但是会封堵同侧的髂内动脉，发生臀肌跛行，影响行走，会阴部缺血也会导致勃起功能障碍，极大影响患者的生活质量。血管外科刘小平主任经多方论证，最终决定利用髂动脉分叉支架系统展开治疗，既要治疗动脉瘤，也不牺牲任何一根血管。

▲术前（左）、术后（右）对比
　　髂动脉分叉支架系统治疗髂动脉瘤是当前医学界的一项新兴技术，目前国内开展的案例极少。同时，此方法常规需要切开上肢动脉，术后恢复时间长；若采用下肢动脉入路，手术难度会进一步加大。血管外科团队仔细研究患者影像资料后，决定**采用****下肢动脉入路，利用全腔内技术进行治疗，真正实现微创**。在心内科导管室及麻醉科全力保障下，刘小平主任带领团队与解放军总医院第一医学中心血管外科许永乐副主任医师精密配合，凭借丰富的临床经验和过硬的手术技巧，克服了支架输送及展开过程中的诸多困难，历时1个半小时，实现了髂动脉瘤的隔绝，并成功重建髂内动脉，造影显示血管通畅，血供良好，手术顺利完成。术后患者非常激动，对手术团队频频称赞。

　　近一年来，海南医院血管外科充分利用腔内微创的优势，对标总医院同质化建设要求，完成了各类血管外科高难度手术，实现复杂血管疾病“不出岛”，真正做到为驻岛官兵和百姓的血管健康保驾护航。
